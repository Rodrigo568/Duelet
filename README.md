# Duelet

Duelet is an open-source study planner that helps you organize assignments, exams and other academic tasks.

The idea is simple: instead of leaving a large task for a single day, Duelet breaks it into smaller tasks and distributes them across your available time.

## Features

- Split large assignments into smaller tasks
- Automatically organize tasks in a calendar
- Plan around deadlines and available study time
- Track progress
- Reschedule unfinished tasks
- Export schedules to Google Calendar, Apple Calendar and other calendar apps
- Manage exams, assignments and study sessions in one place

## Development

Duelet is currently in early development. Some of these features are still being planned or implemented.

The project is open source and contributions are welcome. Feel free to open an issue, suggest a feature or submit a pull request.
